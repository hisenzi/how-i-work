# How I Work

非工程師 × AI Agent × 一人公司的工作系統紀錄。

## 我是誰

UI/UX 設計背景，做的是系統建構 — 不只是介面，而是整個服務怎麼接、資訊怎麼流、成果怎麼累積。

日常工作用 [OpenClaw](https://github.com/openclaw/openclaw) + Claude 作為 AI 協作夥伴。AI 負責初稿展開、資料整理、比對檢查；我負責方向判斷和最終定稿。

## 這個 repo 是什麼

從我的私有工作環境中摘取的公開內容，紀錄一個非工程師怎麼用 AI Agent 建造和維護自己的工作系統。

| 目錄 | 內容 |
|---|---|
| **[system/](system/)** | AI Agent 的設計 — 人設、工作規範、系統架構 |
| **[scripts/](scripts/)** | 自動化腳本 — 備份、記憶維護、每日日誌 |
| **[skills/](skills/)** | 自製的 Agent 技能（OpenClaw Skills） |
| **[stories/](stories/)** | 真實案例，紀錄從問題到解法的思考過程 |
| **[decisions/](decisions/)** | 架構決策紀錄（ADR）— 為什麼這樣做 |
| **[templates/](templates/)** | 可以 fork 的模板 |

## 為什麼公開

Learn in Public。

這些是我在摸索「人 + AI 怎麼協作」過程中的真實紀錄。不是教學，不是最佳實踐，只是一個人的做法。如果對你有幫助，那很好。

## 背景

- 工作方法：文案先行 → SEO/AIO 前置 → 系統設計
- 設計信念：內容與形式要一起成立（Paul Rand）
- AI 協作：分工要清楚，不是炫技
- 底層驅動：從精通邁向自由（Mastery × Purpose × Autonomy）
