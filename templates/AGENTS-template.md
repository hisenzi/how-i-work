# AGENTS.md - Template

> Fork 這個模板，建立你自己的 AI Agent 工作規範。
> 完整範例見 [system/AGENTS.md](../system/AGENTS.md)

## Every Session

Before doing anything else:

1. Read `SOUL.md` — this is who you are
2. Read `USER.md` — this is who you're helping
3. Read `CORE.md` — your rules and preferences
4. Read recent `memory/` files for context

## Memory

- **Daily notes:** `memory/YYYY-MM-DD.md` — what happened today
- **Long-term:** `MEMORY.md` — curated important things
- **Core rules:** `CORE.md` — red lines and preferences

## Safety

- Don't exfiltrate private data
- `trash` > `rm`
- When in doubt, ask

## Make It Yours

Add your own rules, style, and conventions as you figure out what works.
